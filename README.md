# Asmyne Groupe E– MVP

Ce monorepo contient la structure de base pour le MVP de la plateforme Asmyne Groupe .

## Structure
- `frontend/` : Application Next.js (React)
- `backend/` : API Node.js
- `shared/` : Ressources partagées (types, utils, etc.)

## Technologies
- Frontend : Next.js, React
- Backend : Node.js (Express ou équivalent)
- Base de données : PostgreSQL
- Paiement : Stripe, PayPal (intégration prévue)

## Démarrage
Chaque dossier contient son propre README et instructions d’installation.
